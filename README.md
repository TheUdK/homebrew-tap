# Hodm Openssh

## How do I install these formulae?

`brew install hodm/openssh/<formula>`

Or `brew tap hodm/openssh` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "hodm/openssh"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
